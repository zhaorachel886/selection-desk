# 拾句：迭代与验收计划

状态：0.2.0-alpha.3，处于本地 Alpha 验收阶段。源码与本地目录版已包含当前修复；公开安装包状态见 Releases。产品规则以 [PRD.md](PRD.md) 为准，架构见 [tech.md](tech.md)。

## 已实现与证据边界

- 已实现工具条、翻译/问答、两种模型来源、独立后台任务、固定/临时双窗、停止/重试、100 条历史与 Windows Key 加密。
- 已实现坐标来源判断、工具条预加载与自适应位置、同记录语言重译、Markdown 和静默复制。
- 最近基线为 95 项自动测试、类型检查及构建通过；隔离桌面检查覆盖原生启动、公开示例排版和部分交互。
- 用户确认 Chrome、微信、WPS 可以调用，且其 GLM 配置可用。以上不代表全部应用场景、模型质量和安装流程验收通过。

## 下一轮优先顺序

1. 验证真实应用稳定性与选区位置。
2. 量化工具条显示、首段正文到达与上屏耗时，再确定性能改动。
3. 验证阅读操作、完整问答与恢复。新功能在核心体验通过后评估。

## 待验收清单

使用专门公开页面、消息和文档，按实际版本与环境记录结果。以下为尚未完成的整体验收，不将已实现功能重新列为开发任务。

| 范围 | 验收方法 |
| --- | --- |
| 三应用取词 | Chrome、微信、WPS 分别检查中英混排、多行、反向和连续划词；自动入口与复制快捷键分别记录 |
| 工具条位置 | 检查四角、顶部/底部、多显示器与缩放；贴近选区、按钮可用、圆角外透明、隐藏后不误弹 |
| 完整问答 | 每个应用完成翻译、解释、润色、自定义问题、追问、停止和重试；两种来源分别验证 |
| 回答质量 | 解释直接讲含义；润色保留语言、事实、数字和语气；翻译保留条件与结构；追问遵循当前要求 |
| 双窗与后台 | 固定内容不被新问答覆盖；切换不取消后台任务；停止作用于当前记录，输出和草稿不串线 |
| 语言切换 | 同语言不发请求，生成期间禁用，完成/停止后可在同记录重译；草稿和其他后台任务保留 |
| 记录与恢复 | 重启回看、继续追问、100 条保护清理、异常中断与重试；自动清理不取消任务 |
| Codex 历史 | 连续公开问答不意外堆积长期聊天，限制工具执行，实际行为单独验证 |
| 安装与升级 | 安装版/免安装版在项目目录外启动；快捷方式、已有自启和实际进程版本一致；旧实例退出后新版接管 |

## 测速与执行规则

- 分别记录松开鼠标/点击、工具条可见、请求发出、首段正文到达、首段上屏、全部完成。
- 比较模型速度时保持服务、模型、参数和公开文本一致，每组至少 3 次，保留本地原始样本。没有安全入口时先交付静态分析，不读取或导出 Key。
- 每次只处理有证据的缺口；根据改动运行类型检查、测试、构建和必要的隔离原生检查。模拟服务只验证本地链路，不用于宣称模型速度。
- 源码提交不触发发布。发布流程和版本要求见 [release-process.md](../docs/release-process.md)。
