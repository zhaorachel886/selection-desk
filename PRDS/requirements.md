日期：2026-10-22

状态：核心需求已确认。具体功能规则以 PRD 为准；运行兼容性待验证。

## 产品与使用场景

为 Windows 电脑上的阅读和办公提供划词翻译与 AI 问答。用户在不同应用中选中文字，即可在附近操作工具条、查看浮窗回答，减少复制和切换应用。

第一版优先支持 Chrome 网页正文、微信中可选中的聊天消息文字、WPS 文字文档正文。

## 核心功能

- 划词后自动显示「翻译｜问 AI｜复制」工具条。
- 翻译直接显示译文；问 AI 展示原文引用、解释与润色快捷指令、自定义问题输入。
- 浮窗支持流式回答、继续追问、复制回答、拖动、固定和收起。
- 固定窗口保留原内容，新问答在另一个临时窗口显示，最多两个结果窗口。
- 新问答独立处理，已有生成任务继续在后台运行。
- 本机保存最近 100 次独立问答，支持回看、恢复追问、删除和清空。

## AI 接入

回答来源由用户选择 Codex 或智谱／OpenAI 兼容 API；初始默认 Codex，API 预填智谱地址和 glm-4-flash，不自动切换来源。API Key 由用户在设置中输入，Windows 本机加密保存。用户选择浮窗体验优先，Codex 桌面端查看同一对话不作为首版交付条件。日常划词记录由本工具管理，避免自动堆积为 Codex 长期聊天。后续再验证按需转到 Codex 继续、WorkBuddy 和千问办公接入。

## 视觉方向

参考用户提供的豆包划词截图：白底、圆角、轻阴影、紧凑工具条，结果卡片底部放置追问输入框。无需增加朗读、点赞或推荐问题等截图附带功能。

## 开发约束

按本次需求重新设计，允许检查并验证后复用 Git 暂存区中的旧版代码。首版不包含 OCR、WPS 表格/演示/PDF、语音、云同步或直接替换原文。开发与验证由当前 Codex 工作区推进。

## 成功标准

在三个目标应用中完成「选词 → 操作 → 浮窗回答 → 追问或复制」，并验证窗口切换、固定、后台生成、历史恢复及失败重试。取词成功率、模型生成、历史是否持久写入 Codex 均须以实际测试为证据。
