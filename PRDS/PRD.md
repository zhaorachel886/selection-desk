# 拾句：产品需求文档

版本：v0.1；日期：2026-10-22

状态：产品规则、UI 布局与技术方案已确认；Demo 视觉与交互已确认，真实兼容性待验证。

## 1. 目标与范围

面向 Windows 电脑上的日常阅读和办公。用户选中文字后可就地翻译、理解或润色内容，减少复制、切换应用及重新描述问题。

首版优先覆盖 Chrome 网页正文、微信可选中的聊天消息、WPS 文字文档正文。回答来源可选 Codex 或智谱／OpenAI 兼容 API，交付以浮窗内体验为准；Codex 桌面端对话接续属于后续扩展。

## 2. 核心操作

| 操作 | 预期行为 |
| --- | --- |
| 选中文字 | 选区附近出现「翻译｜问 AI｜复制」工具条，尽量避免遮挡原文 |
| 点击翻译 | 打开结果浮窗，直接开始翻译，增量显示译文 |
| 点击问 AI | 展示原文引用、解释与润色快捷指令，以及自定义问题输入框；此时不发起生成 |
| 点击解释或润色 | 立即执行，回答显示在当前浮窗 |
| 发送自定义问题 | 将问题与选中文字一起提交 |
| 点击工具条复制 | 复制原文，显示短暂成功反馈 |
| 点击复制回答 | 复制对应回答正文 |
| 继续追问 | 使用当前问答的上下文 |

仅划词、打开问 AI 或复制原文不发起 AI 请求，不产生历史记录。

## 3. 窗口与任务生命周期

窗口顶部包含功能名称、近期记录、固定和关闭；主体呈现可折叠原文及回答，底部用于追问。输入框右侧共用一个操作位：空闲时显示发送，当前问答生成时显示停止。失败时在问答详情提供重试。

发送按钮在空输入时禁用；当前问答生成时可编辑下一条问题草稿，但不能同时发送，停止或完成后恢复发送。停止按钮始终作用于当前窗口展示的问答，不取消其他窗口或后台问答。切换查看问答时，按钮跟随所查看问答的状态切换。

### 显示、收起与固定

- 工具条出现时保留原应用焦点。主动点击问题输入框后进入输入状态。
- 临时浮窗点击外部收起，可从近期记录或托盘入口恢复。
- 固定浮窗点击外部继续显示，支持拖动。
- 存在固定浮窗时，新问答在另一个临时浮窗显示。
- 最多显示一个固定浮窗和一个临时浮窗。固定临时浮窗时，原固定浮窗解除固定。
- 新问答不覆盖固定窗口的内容。
- 结果窗支持拖动边缘调整大小，常规最小尺寸为 320×300；较小屏幕以可用工作区为限。记住最近一次调整的大小，新开窗口与重启后恢复；不改变已打开的其他窗口。输入框固定在底部，正文独立滚动。
- 每条已发送问题和回答均可单独复制，操作作用于对应内容，不混用最后一条消息。

### 上下文与后台生成

- 新选中文字发起独立问答；同一问答内后续追问保留上下文。
- 新问答切换展示内容，不自动终止已有问答。
- 窗口收起或关闭显示后，对应问答继续在后台生成；近期记录仅显示内容摘要和时间，打开详情后显示生成过程。
- 用户点击停止，只取消对应问答的生成，保留已收到的内容，在问答详情提示已停止。
- 网络或 Codex 连接错误时保留原文、问题、部分回答，提供错误提示及重试入口。
- 退出整个程序与收起窗口不同：退出会结束运行中的任务；下次启动保留已有记录，并标记中断，允许重试，不自动重新发送。
- 回答必须按问答身份关联，后台回答不得串入正在查看的另一段问答。

## 4. 近期记录

### 一条记录的定义

一条记录表示一次独立问答，包含原文、操作类型、用户问题、回答、追问、时间和状态。翻译、快捷指令或自定义问题实际提交时创建记录。

| 行为 | 计数与排序 |
| --- | --- |
| 新选区发起独立问答 | 新增一条，置于最前 |
| 在当前问答继续追问 | 更新同一条记录，置于最前 |
| 失败重试、重新生成 | 保留在同一条记录中，不新增计数；视作用户主动请求更新时间 |
| 打开查看、复制、增量接收回答 | 不增加计数，不改变最后主动请求时间 |
| 停止或失败 | 保留记录和已有内容，仅在问答详情显示相应提示 |

近期记录列表只显示内容摘要与最后主动请求时间，不展示生成中、已完成、已停止等状态文字、标签或替代状态图标。内部仍维护任务状态，用于后台调度、停止、恢复和清理保护；详情页按实际情况显示生成过程、停止提示、失败原因或重试入口。

### 保留与删除

- 本机最多保留最近 100 次独立问答，按最后一次用户主动请求时间排序。
- 新记录加入时，优先清理最久未主动请求、且未显示也未运行的记录。
- 正在显示或执行中的记录受自动清理保护；若最旧记录受保护，顺延到下一条可清理记录。
- 若全部记录均受保护，提示用户先结束或关闭部分任务，不通过取消既有请求来腾出位置。
- 支持查看详情、恢复追问、删除单条、清空。删除或清空正在执行的记录需明确提示会停止对应任务，并由用户确认。
- 删除仅作用于本工具管理的本地记录，不操作 Codex 已有长期聊天。
- 记录与设置在重启后保留；未发送的问题草稿不计入近期记录。

### 与 Codex 历史的关系

工具内历史独立管理，普通划词问答应避免自动增加 Codex 长期聊天。实际技术路线必须验证这一要求。首版不展示尚未打通的「转到 Codex」可执行按钮。

## 5. 默认配置与设置

首版默认配置如下：

| 配置 | 默认值 |
| --- | --- |
| 翻译方向 | 英文及其他外语译为中文，中文译为英文；可切换中文或英文目标语言。相同语言不重复请求，另一语言在同一记录重新翻译；生成期间禁用切换，停止或完成后恢复 |
| 解释 | 默认中文，说明含义，必要时给出简短例子 |
| 润色 | 保留原意和原文语言，提高表达清晰度 |
| 启动 | 手动启动，驻留系统托盘，默认不开机自启 |
| 取词失败 | 手动复制后，通过可配置快捷键调用工具 |

设置页提供回答来源选择、翻译偏好、快捷键与开机启动配置。Codex 提供已保存配置的登录检查，程序路径放在高级项。API 提供地址、模型和写入用 Key 输入框，预填 https://open.bigmodel.cn/api/paas/v4 与 glm-4-flash；Key 不回填到界面，可显式清除，通过 Windows 本机加密存储。

API 测试回答使用固定公开短句，显示首字和总耗时，不创建近期记录、不保存表单修改；保存设置才将来源用于后续请求。来源或模型变更不改变已运行请求，不自动切换服务。已有 Key 不会随未确认的新 API 地址发送；更改地址时要求重新输入 Key。真实可用性、额度、费用与速度需按所选服务及账户验证，不预设免费或必然更快。

## 6. 排除范围

首版不包含图片识字、WPS 表格/演示/PDF、朗读、原文替换、云同步、WorkBuddy 和千问办公接入。跨应用取词不承诺覆盖所有 Windows 窗口。

## 7. 验收

| 范围 | 验证内容 |
| --- | --- |
| 真实取词 | 分别验证 Chrome、微信、WPS 文字中的中文、英文、混排、多行选区，自动取词与备用方式分别记录 |
| 完整问答 | 翻译、解释、润色、自定义提问、追问和复制可完成 |
| 窗口 | 展示不抢焦点，临时窗点击外部收起，固定窗保留，最多两个结果窗，屏幕边缘按钮可见 |
| 后台任务 | 旧问答尚未完成时发起新问答，旧任务继续生成，两段输出分别归属正确记录 |
| 发送与停止 | 输入框右侧按钮根据当前问答切换发送/停止；切换问答后按钮作用于正确对象，草稿保留 |
| 近期记录列表 | 只显示摘要和时间，生成、完成、停止、失败时均不新增状态标签；详情中的错误和重试仍可见 |
| 恢复 | 收起、重启后可回看已保存记录；恢复后可继续追问 |
| 数量与清理 | 多轮追问只计一条；第 101 次独立问答清理正确对象，保护打开或执行中的记录 |
| 异常 | 断网、未登录、停止、失败重试、程序退出均有明确状态且不丢失已保存内容 |
| Codex 历史 | 连续划词不意外堆积长期聊天，以实测结果为准 |

文档完成、代码实现、自动测试和真实应用验收分别报告。旧版代码及测试记录仅作参考，复用部分须重新验证。
