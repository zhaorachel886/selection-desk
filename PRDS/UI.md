# 拾句：UI 设计

日期：2026-10-22；状态：布局、Demo 视觉与交互规范已确认。

## 1. 风格与尺寸

参考豆包划词截图：白色背景、圆角、细边框和轻阴影。使用系统字体，按钮以简洁图标配文字或悬停说明呈现。

工具条使用 14px 标签、18px 图标，按钮高度 28px、水平内边距 8px，外层内边距 4px，总高度 38px。结果窗默认约 380 逻辑像素宽，高度随内容增长并受当前屏幕工作区限制；长内容在主体区域滚动，底部输入框始终可见。窗口可拖动，屏幕边缘自动调整初始位置，尽量避免遮挡选区和固定窗口。

浮窗圆角为 12px，正文左右内边距为 16px，标题栏高 40px，输入框最小高度为 42px。正文保持 14px 字号，通过压缩留白控制整体体积。

## 2. 工具条

```text
[ 翻译 ]  [ 问 AI ]  [ 复制 ]
```

在外部应用选中文字后出现，不抢原应用输入焦点。点击功能后收起；复制直接复制原文，成功静默，失败提示。仅选择文字不调用 AI。

工具条优先位于选区上方居中，上方空间不足时放到下方，靠近左右边缘时收回屏幕工作区。定位使用选区末端所在显示器；只有横向边界可靠时才判断左右空间，多行端点或鼠标拖选不能作为完整文字矩形。极端大选区无法完全避开时，优先保证按钮完整可用并减少遮挡。圆角外保持透明，原生窗口与实际内容区对齐，不留下底部白条；38px 为目标高度，适配系统缩放取整。

## 3. 问 AI 浮窗

```text
┌────────────────────────────────────┐
│ 问 AI              近期记录  固定  × │
│ ┃ 选中的原文……                展开 │
│                                    │
│ [解释这段内容]  [润色这段内容]      │
│                                    │
│ ┌────────────────────────────────┐ │
│ │ 想了解什么？             [ ↑ ] │ │
│ └────────────────────────────────┘ │
└────────────────────────────────────┘
```

- 原文默认最多显示两行；按当前宽度、字号和实际排版判断是否溢出。两行内显示全文且隐藏展开入口，超过两行显示「展开」；展开后显示全文并提供「收起」。
- 点击解释或润色立即发送预设问题。输入自定义问题后发送，才开始调用 AI。
- 发起问答后，快捷指令区域让位给消息与回答；底部输入框用于继续追问。
- 回答完成后，在对应回答下方提供复制回答、重新生成纯图标按钮，悬停显示名称，并保留无障碍名称。失败原因和重试入口显示在问答详情内。

### 发送和停止共用操作位

```text
空闲： [ 继续追问……                ↑ ]
生成： [ 可先输入下一条问题……      ■ ]
```

- 右侧同一位置显示发送箭头或停止方块，并提供「发送」「停止生成」悬停提示及无障碍名称。
- 当前问答未生成时显示发送；输入为空时禁用。
- 当前问答正在生成时切换为停止，不在回答区再放一个独立停止按钮。
- 生成期间可编辑下一条问题草稿，停止或完成后恢复发送并保留草稿。
- 点击停止只取消当前显示问答的生成，保留已收到的回答；其他后台任务继续执行。
- 切换问答时，操作按钮跟随目标问答的状态，不能按全局“有任务正在生成”来切换。

## 4. 翻译浮窗

使用相同窗口结构，顶部增加「自动识别 → 中文/英文」目标语言选择。目标语言采用浅灰背景的小型下拉按钮，展开白色菜单，当前选项显示勾选标记；选择相同语言仅收起菜单，选择另一语言重新翻译。方向键可选择选项，Enter 确认；Escape 优先关闭菜单，点击菜单外部也可关闭。点击工具条翻译后直接生成译文，输入框右侧立即切换为停止。

原文按两行规则展开和收起。译文下方的复制、重新生成使用纯图标按钮，悬停提示名称，并保留无障碍名称。切换目标语言在同一条记录中重新翻译。生成期间暂时禁用目标语言切换，停止或完成后恢复；重译保留追问草稿，不影响其他问答。底部允许继续追问，例如要求换一种表达。

## 5. 固定与临时双浮窗

- 固定窗口用于持续对照，点击外部继续显示。
- 临时窗口处理新问答，点击外部或关闭显示后收起。
- 最多一个固定结果窗加一个临时结果窗；固定临时窗口时，原固定窗口解除固定。
- 新窗口尽量与固定窗口错开，两者均可拖动。
- 新问答切换临时窗口内容，旧问答在后台继续生成。
- 点击近期记录时在临时窗口显示列表，固定窗口仍保留原来的对照内容。

## 6. 近期记录

```text
┌────────────────────────────────────┐
│ 近期记录                     返回 × │
│                                    │
│ 什么是上下文窗口……            刚刚 │
│ ────────────────────────────────── │
│ The main difference……      3 分钟前 │
│ ────────────────────────────────── │
│ 关于本次项目安排……        10 分钟前 │
│                                    │
│ 3 / 100 条                清空记录 │
└────────────────────────────────────┘
```

列表以单行显示 13px 内容摘要与右侧 11px 相对时间，二者间距 8px；不展示生成中、已完成、已停止、失败等状态标签，也不以状态图标或徽标替代。删除操作在行悬停或键盘聚焦时显示。点击一条记录恢复详情，任务仍在生成则继续显示流式内容，失败则显示原因与重试。

后台生成完成时更新记录内容，不自动弹出结果窗，不给列表添加完成提示。清空记录需要确认；如涉及运行中的任务，明确说明会停止对应任务。

## 7. 设置与托盘

托盘菜单：恢复最近问答、近期记录、设置、退出。

设置分为回答来源、翻译偏好、使用偏好。来源选择 Codex 或智谱／兼容 API；Codex 路径收在高级项并提供已保存配置的登录检查。API 显示预填地址、模型与密码形式的 Key 输入，已保存后仅提示留空保留，提供清除操作。公开短句测试回答显示首字与总耗时，不保存其他表单修改。翻译区设置目标语言，使用偏好设置快捷键与开机启动。

回答按已保存的来源执行，不自动故障切换，不提供未打通的转到 Codex 功能。

回答正文采用 14px 字号、1.6 倍行高，段落间距为 8px；生成中和完成后的排版保持一致。

## 8. 组件与 UI 验收

组件包括：三按钮工具条、可拖动窗口标题栏、原文引用折叠区、消息与回答区域、共用发送/停止位的输入框、目标语言选择、近期记录列表、设置窗口和删除确认框。

Demo 需覆盖初始问 AI、翻译、生成、完成、失败、双浮窗、近期记录与设置。重点检查按钮切换位置稳定、停止目标准确、输入草稿保留、历史列表无状态标签，以及长文本滚动时输入框始终可用。

浏览器 Demo 仅验证布局和交互表达；原生取词、跨应用焦点、窗口置顶、多屏定位、Codex 生成与本地持久化须在桌面程序中单独验收。

## 9. 统一规范与自适应

组件的字号、间距、圆角、图标、状态与显示必要性按 [UI-spec.md](UI-spec.md) 确认版执行。初始问 AI 直接呈现原文、快捷提问和输入框。历史列表随内容自然收缩；不为少量记录保留大块空白。

预览画布适配可用宽高；窄屏单浮窗完整显示，双浮窗按画布宽度并排或上下排列，回答滚动时标题栏与输入框始终可用。语言菜单显示在上层，避免被滚动区裁切。外部示例文章的排版与产品窗口的组件规范分开管理。
