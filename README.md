# 拾句（Windows 试用版）

<img src="assets/branding/shiju.png" width="96" alt="拾句图标">

选中其他应用中的文字后，弹出「翻译｜问 AI｜复制」工具条。翻译直接请求所选来源；问 AI 先打开浮窗，输入问题或点击「解释」「润色」后才发送。浮窗可固定、调整大小、追问、停止、复制问题与回答；记录保留最近 100 次独立问答。

## 试用

1. 初始来源为 Codex，需安装并登录 Codex CLI；也可在设置中选择「智谱／兼容 API」，自行填写 Key，地址和 glm-4-flash 已预填。可先测试公开短句，再保存设置。Key 使用 Windows 本机加密，不必发到聊天中。
2. 从 [GitHub Releases](https://github.com/zhaorachel886/selection-desk/releases) 下载文件名包含 `Setup` 的安装版，或另一份 `.exe` 免安装版。后续附件使用 `Shiju` 文件名前缀，程序内仍显示「拾句」。开发者可在项目目录执行 `npm ci`、`npm start`。旧的 0.2.0-alpha.1 本地包不包含本次更新。
3. 在 Chrome、微信或 WPS 文字中选中文字，点击工具条。自动取词失败时，先复制文字，再按 `Control+Alt+D`；快捷键可在设置中修改。
4. 通过托盘菜单可恢复最近问答、查看近期记录、打开设置或退出。

本地问答与设置写入应用数据目录，不写入项目目录。临时窗收起后，已提交的回答继续在后台生成；退出整个程序才中断正在运行的任务。删除正在生成的记录会先提示并确认停止。

API 来源不自动回退到 Codex。测试回答不保存表单修改、不进入近期记录；真实可用性与速度需用户配置 Key 后验证，模拟服务检查不等同于智谱已接通或免费可用。

## 当前版本 0.2.0-alpha.3（2026-10-29）

工具条已修正坐标级别判断、预加载显示和自适应位置；翻译切换目标语言会在同一记录重新翻译。回答支持基础 Markdown，复制成功不再弹提示。翻译、解释、润色与自定义问答使用两条来源共用的任务规范，解释默认简短，润色保留原文语言、事实和语气。源码检查为 95 项测试、类型检查及构建通过；三应用调用由用户确认，位置边界、完整问答和真实模型新提示词效果仍需继续验收。

当前源码版本为 `0.2.0-alpha.3`。本地目录版位于 `release/0.2.0-alpha.3/win-unpacked/拾句.exe`，须保留完整目录；本机桌面快捷方式与已启用的开机启动项均使用此入口。旧试用目录已归档，不再用于日常启动。

GitHub 仓库保存源码，安装版和免安装版通过 Releases 分发。已发布 `0.2.0-alpha.2` 安装包保持原样，不包含后续修复。`alpha.3` 的本地可用状态不等于其安装包已公开发布；公开分发须另走手动 Alpha 发布流程。开发者也可运行 `npm ci`、`npm start` 使用当前源码。

## 开发与验证

`npm run typecheck` 检查类型，`npm test` 检查任务隔离、记录清理、数据恢复和命令校验，`npm run build` 构建开发版，`npm run test:desktop` 检查桌面启动，`node scripts/smoke-selection.mjs` 使用独立 Chrome 测试页检查真实鼠标划词，`npm run package` 构建安装版与便携版，`npm run release:checksums` 核对附件名并生成校验清单。

源码提交与正式分发分开，见 [开发与发布流程](docs/release-process.md)。GitHub 流程仅手动触发，默认不发布。

当前自动检查覆盖任务与记录管理、API 流式协议、加密 Key 与设置边界；本机模拟 API 的隔离 Electron 检查覆盖实际分段显示、停止与重试。用户已实测 Chrome、微信、WPS 均能触发工具条，但报告显示慢及微信/WPS 定位到左上角；本地源码已修正坐标来源，并预加载复用工具条，新位置与体感速度仍需复验。隔离 Codex 适配器曾用公开文本取得真实回答，耗时仍有波动。用户已反馈其 GLM-4-Flash 配置可用且响应快，尚无量化测速。完整三应用回答链路、安装与卸载流程仍需人工验收，本版本作为 Alpha 试用版发布；已发布 alpha.2 附件不随本地源码修改自动更新。

Windows 安装包暂未进行代码签名，系统可能显示未知发布者提示。设置和近期记录保存在原有 `%APPDATA%\\划词助手` 目录，改名不会主动迁移或删除数据。API Key 需使用者自行配置，发布包不包含任何 Key 或 Codex 登录凭据。

`npm start` 运行当前源码的开发版。`node scripts/probe-codex.mjs` 是不经过 Electron 的独立探针，不读取 Windows 系统代理；使用代理的机器需给探针提供相同的 HTTPS_PROXY 环境。探针成功不能代替实际划词、点击及浮窗展示验收。

产品规则与验收目标见 [`PRDS/PRD.md`](PRDS/PRD.md) 和 [`PRDS/plan.md`](PRDS/plan.md)。
