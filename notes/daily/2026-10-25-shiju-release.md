# 拾句 Alpha 发布准备

## 交付内容

版本 0.2.0-alpha.2，统一使用「拾句」及蓝色选区与对话气泡图标。PNG 为运行时图标，ICO 包含 16、24、32、48、64、128、256 像素尺寸，覆盖 EXE、安装程序与快捷方式。保留原有 appId 和应用数据目录，新增安装版，继续提供免安装版。依赖许可证和声明随包分发。

## 本轮证据

- 56 项测试、TypeScript 类型检查通过。
- 离线 Demo 97 项检查通过，原生界面检查确认普通等待文字隐藏，异常重连提示保留。
- 独立资料、公开文本和本机模拟服务的 Electron 集成通过，验证 Key 加密、增量正文、停止、重试和地址变更保护，没有调用真实模型。
- 开发程序和打包程序的启动、IPC、历史页与设置页检查通过，原生取词模块已启动。测试环境快捷键被另一实例占用，记录为限制，不宣称快捷键此次通过。
- 安装版和免安装版构建成功，版本名称和内嵌图标已检查。程序未签名。包内检查未发现用户设置、历史或密钥。
- 未执行实际安装、卸载、三应用完整问答、多显示器或物理边缘拖动验收。

## 发布方式

源码在独立发布副本中整理和提交，旧版 Git 暂存区逐字保留。GitHub 工作流仅可手动触发且限定本次 0.2.0-alpha.2，检查通过后创建预发布，不覆盖已存在的资产。远程提交与发布结果以 GitHub 实际返回为准。
