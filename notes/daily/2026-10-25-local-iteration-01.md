# 本地体验迭代 01

## 本轮交付

- 结果窗口启用 Windows 原生边缘调整大小，工具条保持固定尺寸；结果窗采用不透明原生窗口，以支持系统调整边缘。
- 新增 window-size.json 保存最近一次用户调整的内容区大小。新窗口按显示器工作区恢复，常规最小 320×300；已打开窗口的大小独立。Windows DPI 下存在约 1～2 DIP 的原生边框舍入，恢复不改写保存值。
- 每条用户问题右侧增加复制图标，通过 conversationId/turnId 在主进程取对应内容，不接收渲染端任意待复制文本。Demo 同步复制反馈预览，未新增真实剪贴板写入；原生边缘调整仅在桌面程序验收。
- 修复默认 Codex 路径为空时设置被拒绝的问题，与界面留空自动查找的约定一致。未改造设置布局。

## 验证证据

新增测试先失败，修改后 37 项自动测试及 TypeScript 检查通过，开发构建通过。

隔离 Electron 中植入两条公开问题：两次点击复制后分别得到对应问题；原生窗 isResizable 为 true、最小尺寸生效；缩小后输入框与发送按钮位于可视区域，无横向溢出；保存大小后重启可恢复，保存文件不被 DPI 舍入污染；空 Codex 路径保存成功。

已查看 iteration-small.png 与 iteration-large.png；窗口标题、问题复制和输入区可读。测试脚本位于忽略目录 .runtime/click-diagnostic/iteration-ui-check.cjs。它通过原生窗口 API 调整尺寸并触发用户调整结束事件，不能替代鼠标拖动边缘及多显示器人工验收。
