# 浮窗紧凑化与语言菜单

## 调整

根据体验反馈，将结果窗宽度从 420px 调整为 380px，圆角收至 12px，标题栏从 54px 调整为 44px，正文侧边距从 22px 调整为 16px；压缩引用、空白引导、输入框和历史行的留白，正文保持 14px 字号与 1.6 倍行高。

翻译目标语言由原生 select 替换为独立样式的轻量菜单，提供选中标记、键盘导航、菜单关闭及焦点返回。同语言选择不重新发起生成。
