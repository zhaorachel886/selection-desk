# Demo 前端规范审查与统一

## 范围与依据

依据当前 Demo、项目需求和用户对工具条密度、历史时间显示的体验反馈，对产品窗口、预览控制台、设置、删除确认、字体、间距、信息必要性与窄屏行为进行系统审查。沿用现有产品交互授权完成修改；UI-spec.md 按用户本次请求提前整理为审阅版，未将视觉验收或桌面实现标记完成。

## 发现与处理

| 发现 | 处理 |
|---|---|
| 样式散落，字号、圆角、留白逐个修补 | 集中定义颜色、字号、间距与控件变量，展开 CSS 便于维护 |
| 工具条 14px 字号、较大内边距 | 标签 12px、图标 14px、按钮高 28px，外框总高 38px |
| 时间单独占行，记录强制最小高度 | 摘要与相对时间同一行，短列表自然收缩；仍保存时间用于排序 |
| 初始问 AI 引导文字重复表达输入框与按钮作用 | 直接显示引用、解释/润色、输入框 |
| 翻译与问 AI 回答操作呈现不一致 | 统一纯图标与悬停/无障碍名称 |
| 固定 910px 画布与 650px 以上最小高度造成裁切 | 画布适配宽高，文章和回答独立滚动，单双浮窗自适应 |
| 菜单可能被短回答区裁切 | 使用上层弹出菜单，按视口定位，保留选项与键盘功能 |
| 上层菜单初次键盘聚焦时选项尚未显示 | 打开菜单后再移动焦点，复验通过 |
| scrollIntoView 可能移动隐藏溢出的祖先容器 | 只调整文章自己的 scrollTop，检查画布滚动偏移为零 |

## 验证

最终执行 node demo/verify-ui.cjs，退出码 0，97 项断言通过。视口覆盖 1340×800、1340×595、1000×595、676×595、390×844、541×476。

包含：页面边界、工具条定位、单双浮窗与输入框可见、单行记录、双窗不重叠、菜单真实命中与键盘选择、Escape 关闭层级、设置边界、长内容内部滚动、后台生成保留、停止隔离、草稿保留、历史无状态、选择相同语言不重发、无 JavaScript 异常。

截图复核：676px 历史/工具条/双窗、1340px 问 AI、长内容、翻译、异常、设置与上层语言菜单。记录在 demo/audit-*.png；自动检查明细在 demo/ui-verification.json。

本轮验证为浏览器预览检查，不涵盖真实 Windows DPI、跨应用选区和原生窗口行为。
