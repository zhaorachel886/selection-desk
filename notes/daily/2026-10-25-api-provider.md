# 智谱／兼容 API 本地接入

## 本轮实现

设置新增回答来源 Codex 与智谱／兼容 API，保留初始 Codex 来源，旧设置迁移不自动切换。API 预填 https://open.bigmodel.cn/api/paas/v4 和 glm-4-flash，Key 由用户自行输入。

主进程使用 Electron session.fetch 发送 chat/completions 流式请求；SSE 分帧处理跨块 UTF-8、终态、空回答、断流、HTTP 错误、超时与取消。流式增量沿用 conversationId/requestId 关联，保留原有本地记录和后台任务。模型来源与配置在每次请求开始时固定，在途任务不因设置变化切换，不自动改用其他来源。

model-key.enc 使用 Windows safeStorage 加密，preferences.json 不含 Key。界面仅接收 hasApiKey，不回填保存值；提供清除操作。更换 API 地址而未重新输入 Key 时，不把原 Key 发到新地址。测试回答使用固定公开短句，不写记录、不保存表单，显示首字及总耗时；没有读取 TextLens 的配置、凭据或历史。

修复翻译后的自定义追问仍被当作翻译的问题；追问改用 ask，同时避免首轮翻译出现空问题气泡及无效复制按钮。

## 实测边界与下一步

本轮没有用户提供的智谱 Key，没有进行真实智谱请求、模型可用性、额度费用或速度对比；不宣称已接通真实 GLM 或已经提速。用户从托盘退出并 npm start 后，在设置选择 API、自行填写 Key、点击测试回答并保存，才能开始真实验收。

当前只交付本地源码，未打包、上线或公开发布。阶段文档已同步可选 API 路线，Codex 桌面跳转仍未实现。

官方接口依据：https://docs.bigmodel.cn/cn/guide/develop/openai/introduction 与 https://docs.bigmodel.cn/cn/guide/capabilities/streaming 。它们确认兼容协议与 SSE 能力，不作为 glm-4-flash 在特定账户当前可用或免费、快速的证明。

## 后续用户试用反馈

用户在真实环境中配置 GLM-4-Flash 后明确反馈“非常快”。这确认用户当前配置可获得真实回答，且体感速度明显改善；尚未提供量化首字/完成耗时或逐项操作记录。后续以该配置继续验收回答质量、翻译/解释/润色、追问、停止及三款目标应用；不将单次反馈扩大为全部场景通过，不据此改写新安装默认来源。

## 正常生成提示调整

正常生成不再显示等待模型或连接中的文字，仅保留已有流式光标、无障碍生成状态和停止按钮；重连与失败详情继续显示。公开模拟状态的 renderer 检查先复现旧文字存在，修改后验证普通提示消失、重连可见、停止可用；类型检查和构建通过。已查看 quiet-generation.png。该检查验证界面呈现，没有调用真实模型或改变请求速度。
