# Codex 连接与翻译延迟排查

## 已确认的范围

保留确认的产品规则与窗口交互，修改工具条标签为 14px、图标为 18px。旧版真源仍为 Git 暂存区；`.runtime/old-audit` 是隔离复盘副本。未生成新的 release 包。

## 连接证据

- 现有打包程序的运行时事件显示：浮窗创建成功，initialize、config/read、thread/start、turn/start 均获得响应，随后服务报告 willRetry，未收到正文。
- Windows 启用了本机 HTTP 代理，子进程没有 HTTPS_PROXY/HTTP_PROXY/ALL_PROXY。两个已安装 CLI 在直连测试中均报告 request timed out，无 HTTP 状态码。
- 保持公开文本、登录及程序相同，仅向测试子进程提供已启用的本机代理，取得“天空是蓝色的。”，单次总耗时约 16.9 秒。该结果定位网络差异，不证明延迟稳定。
- 当前源码通过 Electron 的 resolveProxy 取得系统路由，传给 Codex 子进程；已有 HTTPS/ALL 代理优先，不修改全局配置。不向日志或源码写入凭据或真实划词内容。

## 速度证据与边界

以下仅为小样本观测，使用公开短句、同一账户和代理；不能作为 SLA。

| 测试 | 观测 |
| --- | --- |
| 同一模型 gpt-5.6-terra，高思考，两条短句 | 完成约 14.2 秒、11.1 秒 |
| 同一模型，低思考，两条短句 | 完成约 9.7 秒、10.0 秒 |
| gpt-5.6-luna 低档，两条短句 | 完成约 17.5 秒、11.1 秒 |
| gpt-6-luna 低档，两条短句 | 完成约 55.9 秒、10.4 秒 |
| 启动与建线程 | 初始化/读取配置/模型清单合计约 0.3 秒；单次建线程约 0.1～0.2 秒 |

空临时目录中的上下文对照：短句请求的输入约 12901 token；线程内限制项目说明及技能目录后约 8017 token，但完成耗时仍约 14～16 秒。仓库目录测试约 15168 token，包含测试工作区说明的影响。输入较大是观测事实，不能据此认定为全部延迟根因，也未将这组精简参数加入产品。

实际程序选择有一个确定差异：旧连接器按照 where 的有效结果顺序使用 npm CLI；新版优先寻找任意 .exe，跳过 PATH 前面的 npm CLI，选择桌面端捆绑的 0.163.0-alpha.11.2。稳定 CLI 为 0.145.0。相同源码适配器在隔离 Electron 中指定两者，各一次公开请求约 11.5 秒和 23.7 秒；另有一次超时。样本少且服务波动明显，不能将差距全部归因于版本。修复自动查找以遵循 PATH，而非固定版本或安装路径。

旧源码副本与暂存区 codex.ts 的 Git blob hash 相同。在当前桌面端二进制及同一代理下，旧连接器在 thread/start 返回 -32600，未取得可比较的翻译耗时。这不推翻用户之前观察到的旧版快速体验。

## 实施与验收

- 翻译局部指定 low 思考档位，问 AI 保持原设置；不切换全局模型，不启用额外付费优先服务，不新增模型 API。
- 重连事件传入对应问答详情；超时提供网络检查提示；已完成但无正文视为错误。瞬时进度不写入本地历史。
- 工具条在 226×40 视口中三个按钮均完整显示，真实 renderer 的计算样式为 14px 标签、18px 图标；重连提示可见。该检查使用公开模拟状态，不代替真实回答展示。
- 自动测试限制在当前 tests 目录，避免收集隔离旧副本的测试。
- 最终检查：31 项自动测试、TypeScript 检查和开发构建通过。修复后的默认程序查找与系统代理通路在隔离 Electron 中收到公开短句译文“天空是蓝色的。”，首字约 12.547 秒，完成约 12.563 秒，未收到重连事件。配置读取显示全局仍为 high，翻译在 turn/start 局部覆盖为 low；此规则另有回归测试。该结果验证适配器，不等同于真实划词窗口端到端验收。
- 完整本机划词→按钮点击→真实译文展示仍待验收。桌面自动操作工具因无法可靠识别浏览器 URL 中止，不计为程序功能通过或失败。

## 黑色终端与浮窗收起修复

- 本机 npm CLI 的 bin/codex.js 会再 spawn 原生 codex.exe，选项只有 stdio 与 env，没有 windowsHide；外层隐藏选项不传递到这一层。临时浮窗在 blur 后 120ms 收起，因此该启动路径可触发用户报告的焦点问题。
- Windows 解析仍按 PATH 选择 npm 安装，但直接定位同一安装的可选平台包或旧 vendor 布局内原生 codex.exe，由助手以 windowsHide:true、shell:false 启动。不修改安装包或用户 Codex 配置；保持真正外部点击收起的产品规则。
- 两个原生解析回归测试先失败，修复后全部 33 项测试、类型检查与开发构建通过。
- 使用独立数据目录，种入公开样例记录，通过真实 renderer IPC 发起翻译重试、解释和润色。最后一轮三项都完成，实际正文与收到的答案一致，浮窗持续 visible/focused，无 blur；耗时约 8.1、7.2、5.9 秒。前一轮同样三项保持焦点并取得回答，但仅检查后台状态。最初两轮测试窗曾关闭且无 blur，未取得关闭原因，不将其归因于终端，也不计为通过。
- 本项证据覆盖原生窗口、请求、回答渲染和焦点；没有覆盖真实 Chrome/微信/WPS 划词及工具条物理点击。没有生成 release 包。
