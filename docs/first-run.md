# 首轮试用

1. 运行 `Selection-Desk-0.1.0-alpha.1-x64-setup.exe` 安装，或直接运行 portable 版本。安装包未签名，来源和文件校验信息见发布文件。
2. 首次启动打开设置。点击“检查已保存的来源”；如果提示 Codex 需要登录，先完成本机 Codex CLI 登录，或主动切换模型 API 并填写自己的地址、模型和密钥。
3. 保存设置并关闭浮窗。先在浏览器选择一段非敏感英文，点击“翻译”；再选择中文或混排文字点击“提问”，测试连续三轮追问、停止和重试。
4. 如果没有出现工具条，手动复制同一段测试文字后按 `Ctrl+Shift+Space`。快捷键占用时在设置中更换。首次排查时关闭其他划词工具的自动取词，避免多个程序操作同一选区。
5. 需要 agent 读取选区时，从设置导出该客户端配置，导入后重新建立宿主会话。选择测试文字，再让 agent 调用 `get_selection`，检查浮窗显示的请求方与原文，允许本次读取。
6. 按 [验收记录](validation.md) 记录企业微信、文档、浏览器和 agent 中的结果。只记录合成文字或脱敏描述。退出程序使用托盘菜单“退出”。

保存设置后的普通启动驻留托盘。点击托盘图标打开窗口，右键可进入设置。关闭浮窗会释放界面进程，后台取词与本机接入保持运行；退出才会释放快捷键和取词钩子。
