# Selection Desk 0.1.0-alpha.1

Windows 11 x64 的桌面划词浮窗测试版，提供翻译、自定义提问和流式追问，并通过 MCP 将授权选区接入其他 agent。

## 下载与使用
- `Selection-Desk-0.1.0-alpha.1-x64-setup.exe`：当前用户安装版，支持 HTTP 与 stdio 接入。
- `Selection-Desk-0.1.0-alpha.1-x64-portable.exe`：单文件便携版，支持本机 HTTP 接入。
- `Selection-Desk-0.1.0-alpha.1-source.zip`：MIT 许可源码，包含锁文件、测试、文档和连接模板。
- `SHA256SUMS.txt`：发布文件的 SHA-256 校验值。

首次启动进入设置。默认使用 Codex，需要本机 Codex CLI 有可用登录状态；也可主动配置 OpenAI 兼容模型 API。保存后普通启动驻留托盘，关闭浮窗会释放界面资源。

## 核心能力
- 选区工具条、翻译和自定义问题，支持原位追问、停止、重试、复制和固定会话。
- Codex、WorkBuddy、千问办公的 MCP 连接配置导出；外部读取原文每次都需要用户确认。
- 普通选区保留 60 秒，凭据使用系统加密存储。默认无遥测、无开机自启和本地对话正文持久化。
- 自动取词不可用时，可手动复制后按取词快捷键触发；剪贴板自动兜底默认关闭。

## 已完成验证
- 22 个自动测试、类型检查和构建通过。
- 打包程序启动、加密设置、受限界面接口、导出 stdio 真实握手、窗口释放与重建通过检查。
- 本机后台五分钟样本约 223 MiB，平均 CPU 0.0165%；展开设置窗口的启动样本约 363 MiB，仍有优化空间。

## 已知限制
- 这是 alpha 测试版。企业微信等真实应用兼容性、30 次不抢焦点测试、五工作日试用及干净系统安装卸载仍待完成。
- Codex 真实生成和三个宿主的端到端联调尚未完成；WorkBuddy、千问办公当前提供 MCP 取词，反向对话尚未实现。
- 安装包未代码签名，Windows 可能显示未知发布者。请核对来源和校验值。

请使用合成或脱敏文字试用，问题反馈中移除密钥、真实连接配置和原文。完整验收记录见 `docs/validation.md`。
