# 拾句 0.2.0-alpha.2

Windows x64 Alpha 试用版。

## 本次更新

- 产品名称统一为「拾句」，采用蓝色选区与对话气泡图标，应用窗口、托盘、安装程序和桌面快捷方式使用同一标识。
- 提供安装版和免安装版。安装版可创建桌面快捷方式，保留原有应用标识和本地数据目录。
- 划词工具条提供翻译、问 AI、复制；问 AI 支持解释、润色、自定义问题和追问。
- 支持 Codex CLI App Server，或用户主动配置智谱／OpenAI 兼容 API；API 预填智谱地址及 glm-4-flash，Key 由使用者自行提供并在 Windows 本地加密。
- 回答增量显示，正常生成仅保留轻量光标和停止按钮；提供停止、重试、复制问题与回答。
- 支持一个固定窗与一个临时窗、边缘调整大小及最近 100 次独立问答。
- 修复 npm Codex 启动黑色终端、系统代理沿用、自动路径选择和翻译后追问问题。

## 使用

下载安装版 `拾句-Setup-0.2.0-alpha.2-x64.exe`，或直接运行免安装版 `拾句-0.2.0-alpha.2-x64.exe`。升级前从托盘退出旧程序。新安装默认来源为 Codex，需要先安装并登录 Codex CLI；API 使用者请在设置中选择 API 来源并自行填写 Key。

## 验证范围与限制

56 项自动测试、类型检查、开发构建通过；本机模拟 API 的隔离 Electron 集成检查通过，覆盖增量正文、停止、重试、Key 加密保存和地址变更保护。此前 Chrome 公开测试页的划词与空白问 AI 窗已验证。用户反馈其 GLM-4-Flash 真实配置可用且响应较快；该反馈不代表所有模型和应用均已验收。

微信、WPS 文字、完整三应用回答链路、物理拖边与多显示器、全新 Windows 安装及卸载仍待人工验收。Codex 真实请求的耗时存在波动。未实现 OCR、WPS 表格／演示／PDF、语音、云同步或转到 Codex 桌面继续。

安装包未做代码签名，Windows 可能提示未知发布者。包内不含 API Key、Codex 登录凭据和用户问答。模型可用性、费用和速度取决于使用者配置的服务。
