# 拾句 0.2.0-alpha.3

本次更新修正工具条取词坐标、隐藏预加载就绪及屏幕边界定位；工具条优先放在选区上方，空间不足时翻到下方，并约束在工作区内。修复工具条多余白底与系统缩放高度适配。

翻译切换目标语言会在同一记录重新翻译。回答支持基础 Markdown，复制成功保持安静。翻译、解释、润色与问答共用提示词规范，解释默认简短，润色保留原文语言、事实及语气。

95 项测试、类型检查及构建已通过；用户已确认 Chrome、微信、WPS 可以调用。真实模型的新提示词效果、三应用完整回答链路、多显示器和物理划词边界仍需继续验收。本版本为 Alpha，未做 Windows 代码签名。

更新前通过托盘退出旧版，再启动新版。设置和历史沿用原数据目录。仓库提供源码，安装程序及免安装程序通过 Releases 单独分发；源码更新不会自动替换旧程序。
